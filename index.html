Panduan & Tutorial

Pelajari cara melakukan top-up Robux dengan mudah dan cepat

📋 Cara Melakukan Order

  1. Pilih Metode Top-Up

    Tersedia 3 metode: Via Username (tercepat), Via Gamepass (aman), atau Via Login (untuk akun khusus).

  2. Masukkan Data Akun

    Isi username Roblox atau data lain sesuai metode yang dipilih. Pastikan data yang dimasukkan benar.

  3. Pilih Paket Robux

    Pilih paket Robux sesuai kebutuhan Anda. Tersedia dari 100 R$ hingga 10.000 R$.

  4. Lanjutkan ke Pembayaran

    Klik tombol "Proceed to Payment" dan scan QRIS dengan aplikasi banking atau e-wallet Anda.

  5. Tunggu Proses

    Setelah pembayaran terdeteksi, Robux akan dikirim otomatis dalam beberapa menit.

🔍 Cara Menemukan Roblox User ID

Metode 1: Melalui Profil Roblox

  1. Buka website Roblox.com
  2. Login ke akun Roblox Anda
  3. Klik ikon profil di pojok kanan atas, lalu pilih "Profile"
  4. Lihat URL di address bar browser Anda, contoh: roblox.com/users/123456789/profile
  5. Angka setelah "/users/" adalah User ID Anda (contoh: 123456789)

Metode 2: Menggunakan Username (Lebih Mudah)

Di platform kami, Anda cukup memasukkan username Roblox. Sistem kami akan otomatis mendeteksi User ID Anda, jadi tidak perlu repot mencari angka ID secara manual.

❓ FAQ - Pertanyaan yang Sering Diajukan

Berapa lama proses pengiriman Robux?

Biasanya 2-10 menit setelah pembayaran terverifikasi. Jika lebih dari 30 menit, silakan hubungi Customer Service kami.

Apakah data saya aman?

Ya, sangat aman. Kami tidak menyimpan password atau data sensitif Anda. Semua proses dilakukan secara otomatis dan aman.

Metode pembayaran apa saja yang tersedia?

Saat ini kami menerima pembayaran via QRIS yang mendukung semua aplikasi banking dan e-wallet di Indonesia (GoPay, OVO, DANA, ShopeePay, dll).

Bagaimana jika pembayaran sudah dilakukan tapi Robux belum masuk?

Jangan khawatir! Silakan:

  1. Tunggu hingga 30 menit
  2. Refresh halaman order Anda
  3. Jika masih belum masuk, hubungi CS kami dengan menyertakan Order ID dan bukti pembayaran

Apakah bisa refund jika salah input username?

Mohon periksa kembali username sebelum checkout. Jika terjadi kesalahan input, segera hubungi CS sebelum proses pengiriman dimulai. Setelah Robux terkirim, tidak dapat dilakukan refund.

Minimum dan maksimum pembelian berapa?

Minimum pembelian adalah 100 Robux (Rp 14.000), maksimum 10.000 Robux (Rp 1.240.000) per transaksi. Untuk pembelian dalam jumlah besar, Anda dapat melakukan multiple order atau hubungi CS untuk penawaran khusus.
